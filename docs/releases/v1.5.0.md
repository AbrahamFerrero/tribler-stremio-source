# Tribler Stremio Bridge v1.5.0

Status: **local candidate; unreleased; blocked for publication** (2026-11-03).
Base: public `AbrahamFerrero/tribler-stremio-source` v1.4.0,
`18267ac0975f50e201c812db02d1c43cbb2d51ce`. Feature freeze applies.

## Behavior

Bounded OFF-by-default diagnostic capture adds protected native administrative
commands, CLI demo/capture/lifecycle, Trace Workbench and offline JSON/HTML with
English/Spanish labels. Anonymous technical envelopes accept v1–v7; new evidence
covers resolver decisions, final order/score components, observed HTTP/HLS failures
and direct-media admission predicates. Missing causes remain unknown. Private
context is sensitive, explicitly opted in and independently bounded/expired.
The [technical contract](../diagnostics.md) defines budgets, compatibility,
revocation, anonymization and export validation.

The previously developed adjacent-year/title ambiguity refinement is retained
separately from diagnostics. No new ranking, Identity, probe, playback, networking
or Tribler policy is introduced by this remediation. Existing localhost-only,
SSRF/DNS/redirect, recipient-header and Node/Python separation controls remain.

## Distribution and version semantics

Source-only distribution must use the final reviewed path/hash/mode manifest.
No dist, dependencies, caches, real configuration, private reports or private Git
ancestry may be included. npm pack is not an approved source distribution and
npm publishing is not enabled. The CLI demo requires a real Git checkout and an
ignored output directory; a raw extracted source ZIP does not supply that context.
Root package and lock versions are 1.5.0; private remains true. The independent
Stremio protocol-facing manifest version remains unchanged.
PolyForm Noncommercial 1.0.0 and NOTICE are preserved.

## Retained limitations

Playback after resolution remains UNOBSERVED; CLOSED does not mean exhaustive
traceability. HTTP 206, Range, transport verification and Identity markers do not
establish audiovisual correctness. Generic binary MIME and opaque names can fail
direct-video admission. Private omissions and global truncation remain distinct.
PR6, Identity STRICT, R-020, same-user/ACL/race limits and trusted Python-module
risks remain open. No real-provider, Tribler or Stremio smoke is rerun here, and
no private smoke aggregate is distributed. Further investigation is separate work.
