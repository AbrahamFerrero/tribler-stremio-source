# Tribler Stremio Bridge v1.1.0

Historical private development checkpoint, preceding the planned first public
v1.3.0 source release. Results and limitations below belong to that checkpoint;
they do not describe a prior public release or a new validation run.

## Highlights

- Direct HTTP/HTTPS and Tribler appear as separate Stremio choices. Direct playback stays on its selected transport, including failures and seeks.
- Torrent downloads created by the bridge now have persistent ownership and retention state, with `smart`, `ephemeral`, and `keep_all` modes and pin/unpin controls.
- Stream providers run with bounded concurrency and isolated failure handling. A failed configured provider degrades diagnostics without removing healthy sources.
- `/downloads` exposes sanitized diagnostics, including bridge ownership and retention, without tracker URLs or arbitrary Tribler fields.

## Validation

AC1–AC10 passed. The real Direct HTTPS smoke returned two `206` ranges, including a seek. Real Tribler resolved, served bytes, and returned a second seek range. The user confirmed playback and seek for both choices in Stremio Desktop. A Direct failure did not switch silently to Tribler.

The local release gate passed the repository safety scan, typecheck, lint, production build, 272 non-acceptance Node tests, 13 system-acceptance tests, 21 security tests, 285 tests under Node coverage, and 54 Python tests. Both npm dependency audits reported zero advisories. Coverage is informational; no percentage threshold is a release gate. The main GitHub CI workflow also runs dependency audits.

## Security and privacy

The bridge and Tribler API remain loopback-only. Direct HTTP/HTTPS uses SSRF, DNS, redirect, and header protections. The Python host and workers do not receive Tribler credentials. Malformed Tribler responses cannot be reflected through bridge error responses. Locally installed Python modules remain trusted code; the worker audit hook is not an operating-system sandbox. The unsupported CodeQL workflow was removed because this private personal repository does not have GitHub Code Security enabled; it can be restored if that capability becomes available.

## Configuration

Use [.env.example](../../.env.example) to update an existing ignored `.env`. `DOWNLOAD_RETENTION_MODE=smart` is the default. `ARCHIVE_HTTP_STREAMS=true` exposes Internet Archive Direct variants alongside a separately selectable Tribler choice. See the [README](../../README.md) for retention and pin/unpin behavior.

## Known limitations

One manual Tribler seek took about 27 seconds at about 750 KB/s. This is recorded as performance debt and does not block v1.1.0. Swarm availability and external providers remain outside the bridge's control. Local runtime observations do not prove global network anonymity.
