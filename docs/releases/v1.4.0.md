## Behavior

- US-1401/1402: final bridge-owned CORROBORATED > UNKNOWN/unclassified > SUSPICIOUS order, exercised through public Stremio JSON with synthetic fixtures. Technical score, descending seeds, ascending effective size and stable input order break ties within each group. No absolute HTTP(S)/HLS/Tribler priority.
- Final distinct per-provider quota defaults to 50, configurable 1–100 via `STREAM_MAX_RESULTS_PER_PROVIDER`; malformed/empty values fail startup. Above the quota the selected subset can change. The raw safety cap remains 100.
- US-1404: `STREAM_RANKING_DETAILS=true` opts into two-line F descriptions using the resolver's effective JSON policy, final public position, technical score and six components. Default false; scores are not Identity confidence or playback guarantees. Independently rounded totals/components can differ by at most 0.035 points.
- Whole structured language/audio validation and nonnegative safe-integer seeds prevent invalid claims gaining existing points. Generic language yields no public track label; Python validates original characters before trimming and Node retains scoring authority.
- Resolution/codec claims are field-local with explicit precedence and conflicting-claim limits. Effective size prefers valid declarations, otherwise qualified initial non-HLS 206 range evidence; size is shown in GiB/MiB and does not prove integrity.
- Response-header latency includes redirects/root fallback and excludes body, MP4 and HLS verification. It is not body TTFB, throughput or playback speed. Cache hits keep the original timing. These corrections can affect scoring, dedupe representatives, order and final quota selection without changing policy weights.
- Non-system production V8 coverage and uninstrumented system tests are separate mandatory gates. Windows test harness preparation/completion and bounded cleanup diagnostics are retained; production deadlines are unchanged by that work.

The [README](../../README.md#stream-ranking), [HTTP contract](../http-api-contracts.md#v14-stream-array-order)
and [metadata contract](../safe-stream-descriptions.md) give configuration and
boundaries. Qualification, supported contradiction rejection and transport

## Version semantics

Package metadata and the two root lockfile versions are 1.4.0; `private: true`
is preserved. The Stremio addon manifest remains 1.1.0: it is a hardcoded addon
protocol-facing version, independent of the package release metadata in this
source. It already remained 1.1.0 in public v1.3. No shared version constant,
test or release rule requiring synchronization was found. Its compatibility
semantics are not redefined here; changing it would change production and needs
separate review. No dependency is resolved or upgraded during preparation.
