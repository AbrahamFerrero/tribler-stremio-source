## Privacy, security and fixture review

- Host/Origin/Referer/Fetch Metadata/Bearer decisions precede routing/parsing;
  diagnostics joins the administrative family without broadening discovery CORS.
- CLI destinations are canonical HTTP IPv4-loopback/local-root URLs. The actual
  connection uses 127.0.0.1, not DNS or proxy environment variables, and never follows
  redirects. Authorization is header-only; CLI errors do not echo credentials,
  paths, destinations or raw upstream error text.
- Recorder/event/report boundaries rebuild closed primitive schemas, reject
  accessors/extra fields and bound numbers/candidates/events/DTO bytes. Original
  source/URL/title/query/token/header/magnet/infohash data is not diagnostic input.
  Random diagnostic IDs are not private-value hashes. Stop/restart/TTL revoke stale
  handles; detached report reads do not renew retention.
- JSON/HTML injection tests, data equality, dictionary completeness and real browser
  CSP enforcement passed within their documented scope. HTML has no network APIs,
  external resources or playback links. Export is explicit, bounded and no-clobber,
  rejects known symlinks/junctions and unsafe Windows paths, and is not an OS sandbox
  against hostile same-user races or inherited ACLs.
- Canary tests inspect DTO, JSON/HTML, CLI text and actual logger mock calls. The new
  E2E records no additional transport calls. Existing fixture playback regression
  remains separate from diagnostic coverage or audiovisual acceptance.
- New tests/benchmarks use invented data, reserved `.example` names, injected
  addresses and generated reports; no real film, provider inventory, commercial
  query, credential, provider-specific workaround or third-party media asset was
  added. The code license remains PolyForm Noncommercial 1.0.0. Existing media
  reference licenses/attribution remain in [third-party media](../third-party-media.md);
  that code license does not relicense third-party works.

`security:repo --all` is supporting evidence only; it does not inspect all historical
content, dependency bundles or license obligations. The separate history inventory,
diff review, test evidence and dependency artifact check address additional surfaces
but do not substitute for final publication approval.
