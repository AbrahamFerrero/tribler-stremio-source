## Reproduce against the exact future candidate

Use a clean isolated checkout, reviewed synthetic fixtures and no real `.env`,
provider profiles or corpora. Record the exact candidate content manifest,
platform, Node/npm/Python versions, command exit codes and skips. Required
development Node engine ranges are in the [README](../../README.md).

```text
npm ci
npm run security:repo
npm run typecheck
npm run lint
npm run test:all
npm run test:acceptance
npm run test:security
npm run coverage
npm run test:system
npm run build
npm audit
npm audit --omit=dev
```

From `python-adapter-host/`, with recorded effective Python tooling versions:

```text
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python -m coverage run --branch -m unittest discover -s tests -v
python -m coverage report --include=adapter_host/*
```

Coverage includes all configured non-system tests; system tests run separately
without V8 and remain mandatory. `npm run test:complete` chains general,
acceptance and system suites without coverage, stopping on any failure.
Synthetic checks do not certify audiovisual tracks, real providers/swarms,
Stremio compatibility across clients or unrestricted Kodi modules.
